# ЛОФТ эко-бар — статический сайт

Готовая версия для GitHub Pages. Сервер, Render и сборка не требуются.

## Публикация

1. Загрузить в корень репозитория всё содержимое этой папки, сохранив структуру `assets/fonts`.
2. В GitHub открыть `Settings → Pages`.
3. В `Build and deployment` выбрать `Deploy from a branch`.
4. Выбрать ветку `main`, папку `/(root)` и нажать `Save`.
5. Дождаться появления адреса GitHub Pages и проверить сайт на телефоне и компьютере.

Пока не добавлять `CNAME` и не менять DNS домена `loftecobar.ru`: сначала проверяется временный адрес GitHub Pages. Старый репозиторий и Render остаются резервом.
